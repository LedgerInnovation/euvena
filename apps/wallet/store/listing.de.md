## Beschreibung (beide Stores)

Euvena macht aus einer SEPA-Überweisung einen QR-Code und wieder zurück.

GELD ANFORDERN
Gib einen Betrag ein, auf Wunsch auch den Verwendungszweck, und Euvena zeigt einen EPC-QR-Code (GiroCode), das Format, mit dem viele europäische Banking-Apps eine Überweisung ausfüllen. Teile die Anforderung als Link oder behalte sie im Verlauf auf deinem Handy. Mehrere Empfänger lassen sich speichern, für einen Haushalt, einen Verein oder ein kleines Geschäft.

ANFORDERUNG BEZAHLEN
Scanne einen Zahlungscode oder füge eine geteilte Anforderung ein. Euvena zeigt genau, was der Code enthält: Name, IBAN, Betrag und Referenz. Dann übergibt Euvena die Angaben als payto-Link an eine App, die ihn annimmt, oder lässt dich sie Feld für Feld in deine Banking-App kopieren. Ein Code, der eine Prüfung nicht besteht, wird ganz abgelehnt und nie nur teilweise angezeigt.

EN-18184-CODES
Euvena liest auch EN-18184-Codes (EPC024-22) für den Point of Interaction, die die Empfängerdaten enthalten, und erstellt sie, sobald du die Angaben eingibst, die dir dein Zahlungsrahmenwerk zugewiesen hat.

KEIN KONTO, KEIN SERVER, KEINE DATEN
Euvena hat keine Konten und kein Backend. Die App hält und bewegt nie Geld und kontaktiert keine Bank: Jede Zahlung wird in deiner eigenen Banking-App ausgeführt und freigegeben. Empfänger und gespeicherte Anforderungen liegen auf deinem Handy, nie auf einem Server von uns, und eine Exportdatei überträgt sie auf ein anderes Handy, wenn du das möchtest. Es wird nichts erhoben, verfolgt oder weitergegeben.

# Store material

What the App Store and Google Play ask for beyond the build, kept beside the code it describes.

| File | Use |
| --- | --- |
| `listing.en.md`, `listing.de.md` | Name, subtitle, short and full description, keywords, category |
| `review-notes.md` | Notes for App Review; `review-code.png` is the sample request as a QR code to attach |
| `privacy-policy.md` | The privacy policy text, to publish at a public address |
| `declarations.md` | Answers for App Privacy, Data safety, the financial features declaration, content rating, export compliance and trader status |

Screenshots are taken from a build on a device or simulator and are not kept here.
